Stage 3 runs a different vendor from stage 2 on purpose, so the second opinion isn't the same brain grading its own homework. Every hop is a zod contract with strict JSON-schema at the API layer and one retry that feeds the parse error back to the model.

Stage 4 is the load-bearing idea. A model will happily invent a contradiction that reads perfectly and cite a line saying nothing of the sort. So the pipeline doesn't ask another model whether to believe it. It reopens the file and checks the quote. Findings whose evidence isn't there get killed, and the kill list is rendered in the report, because a validation step whose output you can't see isn't a validation step.

Where it broke

Three separate false positives, all from the check I'd described as “deterministic, nothing to hallucinate”.

  1. .claude/commands/ wasn't classified, so a repo organising context as slash-commands scanned as empty. It reported a bug in my scanner as a fact about the repo.
  2. I sparse-cloned shapeshift/web, so .claude/ was never fetched and every referenced path looked deleted. 9 confident false positives. Now it refuses to run on a partial tree.
  3. ./scripts/gh.sh in .claude/commands/dedupe.md was resolved relative to the markdown file rather than the repo root, where slash-commands actually run. All 28 refs in anthropics/claude-code flagged broken while scripts/gh.sh sat in the tree. 28 → 0, score 54 → 74.

The honest lesson: determinism bought reproducibility, not correctness. A rule that is confidently wrong is worse than a model that is uncertain, because nobody thinks to audit the rule.

Prior art

Not a new idea and I won't pretend otherwise. ccmd.dev does token-bloat and contradiction analysis on a pasted CLAUDE.md. claudelint ships 116 rules. AgentLinter ships 51 checks. If you just want “is my CLAUDE.md too big”, use one of those, they're further along.

Two things here differ. Those tools are root-file centric and don't examine whether your accumulated agents and skills have colliding remits. And a rule engine can't hallucinate because it never generates, which is also its ceiling: it catches only what someone could express as a rule. Semantic contradiction across seventy files needs a model, and a model's findings are worthless unless verified. Rule linters catch what a rule can express; this catches what needs judgement, then proves the judgement wasn't invented.
